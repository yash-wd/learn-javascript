Brand new? Read this first

Start in 3 simple steps

If you have never written code before, this is everything you need to do. Don't worry about any of the folders yet — you only ever touch two of them.

1

Install Node.js

It's a free program that runs JavaScript on your computer. Get it from nodejs.org (pick the "LTS" version) and install it like any other app. This is your one-time setup.

2

Open your first lesson

In your editor, open lessons/01-variables.js and read it top to bottom. Every line is explained in plain English, and // => shows you exactly what it prints.

3

Run it & repeat

In a terminal, type node lessons/01-variables.js and press Enter. Compare the output. Then open lesson 02 and repeat — that's the entire course.

# 1. run your very first lesson node lessons/01-variables.js # 2. when you finish, go to the next one node lessons/02-data-types.js # …keep going in order, all the way to lesson 52.

👉 The golden rule: read it → run it → change a value and run it again → only move on once it makes sense. That's how it sticks.

✍️ Practice each lesson: every lesson ends with a few PRACTICE questions, and lessons/solutions/ has a matching NN-solutions.js file for each one to write your own answers in (lessons 48–50 ship with worked answers to compare against).

First-timer questions

Help & common questions

New to all of this? These answer the things that trip people up at the start.

I see lots of folders. Which ones do I actually use?

Only two: lessons/ (the 52 lessons you learn from) and projects/ (the apps you build later). You can completely ignore assets/, bundle/ and tools/ — those are just packaging for this website and the offline PDF.

What is a "terminal" and how do I open one?

The terminal is a window where you type commands. On Windows it's "Command Prompt" or "PowerShell"; on Mac it's "Terminal". Easiest of all: open this folder in a code editor and use its built-in terminal, then type node lessons/01-variables.js.

Do I need to install anything?

Just one thing: Node.js from nodejs.org (the "LTS" version). That lets you run the lessons. For the projects and the browser lessons, you also use a normal web browser — which you already have.

What about the lessons marked "BROWSER"?

A few lessons (23, 24, 46) change web pages, so they run in a browser instead of the terminal. Open playground.html, change the line near the bottom to point at that lesson, then open the page and press F12 to see the output in the Console.

How long will this take?

There's no clock. Some lessons take ten minutes, some take an hour. Go at your own pace and don't move on until the current lesson makes sense. Finishing all 52 plus the projects is a genuine, job-ready foundation.

Can I read it all offline or on paper?

Yes. Every lesson is bundled into a single PDF and Markdown file you can read or print.
